# images

Web-sized copies only. One folder per section, matching the data file names.

- 1600 px on the long edge, JPEG at 80% quality
- lowercase-hyphenated filenames, no spaces
- `images/ppc/thanjavur-1997-cover.jpg` is written in the JSON as `"ppc/thanjavur-1997-cover.jpg"`

Keep original scans outside this repo. `.gitignore` excludes an `originals/` folder
if you put one here.
